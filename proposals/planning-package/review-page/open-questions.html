Q22: Which propositions the measure speaks to (the S3 join) resolved

QC's six propositions are conditional statements ("when X, then Y") that each name two or three categories, and S2 measures one theme's prevalence. Which proposition does the measured number speak to, and what verdict may such a row carry?

How it was settled: A written rule, no test, because a prevalence cannot confirm or contradict a conditional: before any verdict is drafted, each proposition is mapped to the measure only if it names a QC category the measured code qualified for (Q15); otherwise it is "silent: not measured", with the reason. Measuring a proposition's condition and outcome together, so a row could converge or diverge, is a later slice's choice.
