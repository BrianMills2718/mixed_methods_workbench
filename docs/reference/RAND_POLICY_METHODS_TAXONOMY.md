# RAND Policy-Research Methods Taxonomy

## Purpose and status

This page preserves a historical policy-research methods taxonomy from the
`rand_ai_analysis` project for discovery, comparison, and future method-profile
crosswalks in the Mixed Methods Workbench.

This is a **source reference**, not a workbench authority, validated ontology,
exhaustive universe of policy methods, or implemented workbench capability.
Several entries are aliases or neighboring concepts rather than mutually
exclusive methods. Using this vocabulary does not alter the workbench's method
boundaries or license a mixed-methods claim.

## Intended workbench use

Use this page as candidate vocabulary when scoping a study, comparing method
profiles, or designing a reviewed crosswalk. Preserve the original labels in
the source column and record any normalization, aliasing, splitting, merging,
or exclusion as a separate reviewed transformation. Do not silently promote
these labels into executable contracts or empirical claims.
