# Workbench Contract V1 Synthetic Fixtures

These files are synthetic contract fixtures. They are not generated by
`qualitative_coding`, `process_tracing`, or `theory-forge`, and they are not
research evidence.

Purpose:

- define the first machine-readable workbench seam;
- make forbidden method-boundary mistakes executable in `make check`;
- give engine-local implementing agents a target shape for future real export
fixtures.

Replacement rule: real fixtures must replace these only after the producing
engine records the source command, producer commit, package hash, caveats, and
validation result.

Validation:

```bash
make validate-fixtures
```
