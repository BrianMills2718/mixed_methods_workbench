# Mixed Methods Workbench

This directory is a planning scaffold for a future qualitative and mixed-methods
research workbench. Read `PROJECT.md` and `docs/ARCHITECTURE.md` before making
changes.

Core rule: compose `qualitative_coding` and `process_tracing` as method engines
through typed contracts before moving implementation code or merging repos.

Important files:

- `PROJECT.md` - product goal and thesis.
- `CLAUDE.md` - operating rules for agents.
- `docs/ARCHITECTURE.md` - design-plan artifact with modality split, diagrams,
  dependency subplans, and acceptance criteria.
- `contracts/shared_contracts.md` - initial shared contract sketch.
- `docs/plans/001_walking_skeleton.md` - first vertical slice.
- `docs/CONCERNS.md` - live concern register.

Do not claim this workbench is implemented until a vertical slice exists. Do not
flatten method-specific estimands into one generic confidence score.
