# Three-method pilot of the revised instrument

Status: exploratory readout

This pilot re-expresses three deliberately different methods using phases,
analytical moves, and connection types. It uses the already frozen methodology
sources and audited blind reruns; it does not perform another methodology
survey.

The methods were selected to stress different structures:

- constructivist grounded theory: emergent and cyclic;
- RCT causal-effect estimation: prespecified with prohibited returns;
- policy option appraisal: branching evidence, explicit values, advice, and an
  accountable decision boundary.

## 1. Constructivist grounded theory

### Plain-language journey

```text
Frame an open inquiry
  → gather rich initial data
  → code, compare, and write memos concurrently
  → develop provisional categories
  → identify what the categories still need
  → collect theoretically targeted data
  → recode, compare, and revise
  → judge adequacy
      ↺ return for more targeted data when useful and possible
  → integrate categories into a bounded interpretive theory
      or stop with a descriptive/partial account
```

### Phases and analytical moves

| Phase | Analytical move | Inspectable output | Method-owned rule or refusal |
| --- | --- | --- | --- |
| Orient | Frame the inquiry and researcher position | Open question and reflexive frame | The question must orient without fixing categories in advance. |
| Begin inquiry | Plan and gather rich initial data | Sampling rationale, corpus increment, field notes | Richness is analytic, not statistical representativeness. |
| Analyze | Conduct provisional initial coding | Initial codes and analytic questions | Codes remain close to actions and meanings; forced prior categories are flagged. |
| Analyze | Compare incidents, codes, participants, and settings | Comparison record and variation map | A pattern needs contrasts and negative cases, not repetition alone. |
| Analyze | Write analytic and reflexive memos | Memos, rationale, open questions, sampling leads | Memoing develops the analysis and makes researcher interpretation visible. |
| Conceptualize | Select focused codes and develop categories | Focused codes, categories, properties, gaps | Significance is conceptual; a topic label is not a developed category. |
| Iterate | Design and conduct theoretical sampling | Targeted sampling plan and new data | Sampling follows category needs; rereading a fixed corpus is not new theoretical sampling. |
| Iterate | Recode and revise categories | Revised categories and disconfirming cases | New data may split, relate, qualify, or reject categories. |
| Appraise | Argue category adequacy | Adequacy assessment and residual gaps | Adequacy is reasoned from development and variation, never a mechanical count. |
| Integrate | Construct and delimit the theory | Integrated account, scope, reflexive limits | If categories do not form a supported account, return a partial or descriptive result. |

### Connections that matter

- Coding, comparison, and memoing exchange artifacts and may occur
  concurrently.
- An adequacy judgment is a control gate: it authorizes integration or returns
  the study to theoretical sampling.
- The return is feedback, not evidence flowing backward in time.
- Lack of access can terminate with a bounded incomplete account rather than a
  false saturation claim.

### What may be reused

- Shared mechanics candidate: source anchoring, versions of codes/categories,
  lineage, review records, feedback, and bounded refusal.
- Shared shell candidate: present an evolving artifact and disconfirming
  evidence for a method-owned adequacy judgment.
- Method-owned: theoretical significance, constant comparison, theoretical
  sampling, category adequacy, and reflexive integration.

## 2. RCT causal-effect estimation

### Plain-language journey

```text
Define the causal objective and estimand
  → freeze trial design and analysis plan
  → create concealed random allocation
  → enroll, assign, deliver, and observe outcomes
  → lock and reconcile the analysis data
  → audit whether randomization and conduct remain credible
  → estimate the intention-to-treat effect
  → stress missing-data and intercurrent-event assumptions
  → issue a bounded superiority conclusion
  → report transparently

Seeing outcomes must not silently rewrite the objective, estimand,
primary outcome, allocation, or primary analysis.
```

### Phases and analytical moves

| Phase | Analytical move | Inspectable output | Method-owned rule or refusal |
| --- | --- | --- | --- |
| Define | Specify objective and estimand | Frozen causal contrast and estimand attributes | “ITT” alone does not specify the effect measure, intercurrent events, or missingness. |
| Design | Prespecify design, sample size, and analysis | Protocol, allocation design, SAP, sensitivity plan | Choices precede assignment and outcome access. |
| Assign | Generate unpredictable concealed allocation | Sequence and concealment audit trail | Predictable or manipulated allocation blocks the ordinary randomized warrant. |
| Conduct | Enroll and assign eligible participants | Randomized cohort, assignments, baseline | Eligibility precedes assignment; all assigned units enter the ITT cohort. |
| Conduct | Deliver conditions and track departures | Delivery, contamination, deviations, intercurrent events | Adherence is observed but does not redefine assignment. |
| Measure | Ascertain the primary outcome consistently | Outcomes and missingness indicators | The same prespecified definition and clock apply across arms. |
| Govern | Lock data and account for participants | Locked dataset and flow ledger | Undocumented deletions, reassignment, or post-lock changes invalidate the ordinary analysis. |
| Appraise | Audit randomization and conduct | Validity diagnostics | Baseline significance testing neither creates nor cancels randomization. |
| Estimate | Estimate the primary ITT effect | Effect estimate and uncertainty | Do not substitute post-hoc per-protocol or favorable subgroup results. |
| Stress | Run prespecified sensitivity analyses | Assumption-stress results | Sensitivities qualify rather than replace the primary result. |
| Conclude | Judge superiority within scope | Supports, does-not-support, or indeterminate conclusion | Failure to show superiority is not equivalence, mechanism, or a population-wide effect. |
| Report | Expose conduct, flow, results, and deviations | Auditable trial report | CONSORT reporting cannot repair a defective design or analysis. |

### Connections that matter

- The protocol and estimand are retained context for several later moves.
- Prespecification is both a control gate and a temporal/information-access
  barrier.
- Outcome-informed return to the confirmatory design is a prohibited
  transition. If it occurs, the new analysis is separately labeled exploratory.
- Sensitivity analysis branches from the primary analysis and rejoins at the
  conclusion; it does not overwrite the primary result.

### What may be reused

- Shared mechanics candidate: version freezing, access/timestamp records,
  lineage, validation, review state, and downgrade/refusal.
- Shared shell candidate: execute a frozen analysis plan, present diagnostics,
  and require review before publishing a bounded result.
- Method-owned: estimand construction, randomization warrant, ITT estimation,
  missing-data/intercurrent-event handling, and causal interpretation.

## 3. Policy option appraisal

### Plain-language journey

```text
Establish the problem and reason for intervention
  → define scope, business-as-usual, objectives, and constraints
  → generate a broad option set
  → shortlist transparently
  → characterize options comparably
  → analyze in parallel:
       monetized social value
       non-monetized effects
       distributional consequences
       risk and uncertainty
  → compare without hiding conflicts or value judgments
  → advise, advise conditionally, or withhold preference
  → accountable decision-maker decides
  → monitoring and evaluation inform a future appraisal version
```

### Phases and analytical moves

| Phase | Analytical move | Inspectable output | Method-owned rule or refusal |
| --- | --- | --- | --- |
| Diagnose | Establish the intervention rationale | Problem account and case for action | A sponsored solution is not itself evidence of a problem. |
| Bound | Define scope and business-as-usual | Population, horizon, jurisdiction, counterfactual | Social value is incremental to an explicit baseline. |
| Direct | Set objectives, constraints, and success factors | Objective hierarchy and authority record | Objectives describe desired outcomes rather than encode a favored option. |
| Generate | Construct the longlist | Materially distinct options including BAU/do-minimum | Do not limit the option space to sponsored proposals. |
| Screen | Select the shortlist | Shortlist and rejection log | Criteria are explicit and consistently applied; failed options may return for redesign. |
| Characterize | Specify each shortlisted option | Comparable option models and dependencies | Options require comparable maturity; packages must expose overlaps. |
| Analyze | Map social impacts | Impact register and affected parties | Include material effects regardless of who bears them or whether they are fiscal. |
| Analyze | Quantify, value, and aggregate defensible impacts | Valued impacts and social-value metrics | Avoid false precision, inconsistent bases, and double counting. |
| Analyze | Structure non-monetized effects | Criteria, scores, weights, rationale | Weights are value judgments, not empirical facts or a sole mechanical rule. |
| Analyze | Disaggregate distributional effects | Who gains, who loses, and access differences | Aggregate benefit cannot erase consequential subgroup harms. |
| Stress | Analyze risk and uncertainty | Scenarios, sensitivities, switching values | A single forecast cannot be presented as certain. |
| Compare | Form the comparative case | Visible trade-offs, conflicts, robustness | Do not collapse conflicting evidence into one opaque score. |
| Advise | Prefer, conditionally prefer, or withhold preference | Bounded analyst advice | Advice is not approval; no preference is valid when rankings are fragile. |
| Decide and learn | Record the accountable decision and feedback needs | Decision record, monitoring plan, future review trigger | A later evaluation starts a new appraisal version rather than rewriting history. |

### Connections that matter

- Monetized value, non-monetized consequences, distribution, and uncertainty
  are parallel artifact flows that join at comparison.
- Objectives and weights cross value/goal-authority boundaries.
- Comparison is a control gate into advice; advice is an artifact flow to the
  decision-maker, not the decision itself.
- Monitoring and evaluation create feedback for a future version.

### What may be reused

- Shared mechanics candidate: option identity, evidence custody, parallel
  branches, review state, explicit values, feedback, and version lineage.
- Shared shell candidate: apply transparent criteria to alternatives, preserve
  rationale, expose sensitivity, and allow no robust preference.
- Method-owned: intervention rationale, social valuation, distributional
  treatment, criteria/weight legitimacy, comparative appraisal, and advice.

## Pilot result

The three-level format explains the earlier count disagreements better than a
flat row ledger:

- broad phases can be grouped differently without affecting reuse claims;
- analytical moves split where artifacts, warrants, origins, authority, or
  topology change;
- execution details remain available for implementation audits but no longer
  manufacture new method capabilities;
- non-data arrows are understandable as retained context, gates, feedback, or
  prohibited transitions.

The format passes an internal traceability check on these three methods: every
move has an inspectable output, method-owned boundary, and understandable
connection type. It has not passed an independent usability review or a broader
portfolio stress test. It remains possible that another method family exposes
a missing connection type or an unstable analytical-move boundary.
